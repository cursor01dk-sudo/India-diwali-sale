--------------------------------------------------------------------------------
• Password Hashing:
  All user and admin passwords are automatically salted and hashed using bcrypt (10 rounds).
  Plaintext passwords are NEVER stored in the database or exposed via API (select: false).
  No unauthorized entity or database snooper can decrypt or read stored credentials.

• Session Tokens:
  Stateless, tamper-proof JSON Web Tokens (JWT) signed with a high-entropy secret key.
  Delivered in secure HttpOnly cookies to protect against XSS and token hijacking.

• Payment & UPI Gateway Encryption:
  All payment signatures and merchant callbacks are verified using cryptographic SHA-256
  hashes and HMAC checksums. Transaction payloads cannot be spoofed or replayed.

• Top Selling Sort Pipeline:
  Universal priority sorting ({ isTopSelling: -1, priority: -1, createdAt: -1 }) guarantees
  that pinned items are instantly placed at the top across all catalog rails, categories,
  and homepage sliders with zero database leaks.
